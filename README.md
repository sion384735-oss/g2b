# 비드인사이트 MVP

나라장터 공고를 검색하고 관심 공고·마감 일정·낙찰 결과를 관리하는 한국형 B2B 입찰정보 서비스 MVP입니다. 인포21C의 업무 흐름을 참고했지만 브랜드와 화면은 독자적으로 설계했습니다.

## 현재 구현

- 반응형 랜딩 페이지와 통합검색
- 공사·용역·물품 필터, 빈 결과, CSV 다운로드
- 공고별 상세정보와 고유 공유 메타데이터
- 낙찰 결과, 사용자 대시보드, 관리자 운영현황
- ChatGPT 계정 기반 로그인 연결점
- D1용 입찰·관심공고·검색조건·알림·감사로그 스키마
- 공식 OpenAPI adapter, 재시도·타임아웃·서버 전용 키 구조
- API 키 없이 작동하는 한국어 데모 데이터

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
cp .env.example .env.local
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다.

## 환경변수

- `DATA_GO_KR_SERVICE_KEY`: 공공데이터포털에서 발급받은 서비스키
- `G2B_API_BASE_URL`: 신청한 나라장터 API 문서의 Base URL
- `NEXT_PUBLIC_APP_URL`: 서비스 주소
- `EMAIL_API_KEY`: 이메일 발송 provider 키
- `EMAIL_FROM`: 발신 이메일

서비스키는 서버의 `lib/g2b.ts`에서만 사용하며 클라이언트 코드로 전달하지 않습니다. OpenAPI의 업무별 operation 이름은 공공데이터포털에서 실제 활용신청한 서비스 문서를 기준으로 설정해야 합니다.

## 데이터 동기화 원칙

사용자 검색마다 외부 API를 호출하지 않습니다. 스케줄러가 공고를 수집하고 `(bid_number, bid_order)`로 upsert한 뒤 서비스 검색은 D1을 사용합니다. API 응답은 adapter에서 내부 모델로 정규화하며 최대 3회 재시도합니다. 날짜는 서비스 계층에서 Asia/Seoul 기준으로 저장·표시합니다.

## 다음 운영 단계

1. 공공데이터포털에서 `조달청_나라장터 입찰공고정보서비스` 활용신청
2. 실제 operation별 동기화 작업과 D1 upsert 연결
3. Resend 등 이메일 provider 연결 및 알림 중복방지 키 적용
4. 사업자 회원용 외부 인증이 필요하면 배포 플랫폼의 지원 방식 확정 후 추가
5. 카카오 알림톡, 발주계획, 계약과정, 업체 분석 순으로 확장

실제 투찰은 지원하지 않으며, 모든 공고 상세에는 나라장터 원문 최종 확인 안내를 표시합니다.
